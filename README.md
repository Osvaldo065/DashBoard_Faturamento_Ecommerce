
# DASHBOARD DE FATURAMENTO DE VENDAS ECOMMERCE

## DESCRIÇÃO DO PROJETO

* Este projeto apresenta um dashboard interativo para o monitoramento do faturamento de vendas de um ecommerce, oferecendo uma visão clara e centralizada da performance financeira através de métricas e indicadores. A ferramenta permite a visualização de dados de receitas, facilitando a análise de tendências, a identificação de áreas de sucesso e a tomada de decisões estratégicas para o crescimento do negócio. 

## FERRAMENTAS UTILIZADAS:

* POWER BI 
* DATASET DE FATURAMENTO - EXCEL

## REFERÊNCIAS

* DATASET EXTRAÍDO - KAGGLE 

## COMO UTILIZAR?

* Realizar buscas por período através do filtro.
* Gráficos clicavéis com interação dinamica.
